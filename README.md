# Mini Biblioteca

Aplicação de console em Java para gerenciar o acervo de uma biblioteca:
cadastro de livros e usuários, empréstimos e devoluções.

## Escopo

**O sistema faz:**
- Cadastrar, listar e remover livros
- Cadastrar usuários
- Emprestar e devolver livros
- Validar regras (ex.: não emprestar livro já emprestado)
- Salvar os dados em arquivo

**O sistema não faz (por enquanto):** interface gráfica, banco de dados,
login e multas.

## Requisitos

- [ ] RF01: cadastrar livro com título, autor e código único
- [ ] RF02: impedir empréstimo de livro já emprestado
- [ ] RF03: registrar data de empréstimo e de devolução

## Tecnologias

- Java (versão que você instalou)
